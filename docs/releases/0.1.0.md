Daymark Habits is a habit and routine tracker for Obsidian by niyoj.

- Today checklist with routine groups, remaining-first tasks, and accessible completion controls.
- Four embeddable Markdown views: Habit Board, Weekday Patterns, Weekly Consistency, and Calendar Overview.
- Daily, weekday, and custom task schedules; dated history for routine edits.
- Scheduled-day streaks, historical check-in correction, and two shared manual freezes per month.
- Optional `habit-widget.json` snapshot for the read-only Scriptable companion.
- Local data, no accounts, network requests, telemetry, or paid features.

Export includes pending saved check-ins and uses Obsidian's Vault API. Automatic export refreshes after changes, on startup, and after a detected local-date rollover while Obsidian is running.

This initial release is not yet listed in the Community directory. Use the attached ZIP for manual installation, or install the repository through BRAT. Install into `.obsidian/plugins/niyoj-daymark/`.

The plugin supports mobile-compatible APIs. Phone-width layouts were checked on desktop; physical iOS/Android device behavior and Scriptable/iCloud access remain unverified. See the README for the export schema and companion setup.
