Habit Board now includes lifetime **Routine stats**: Current streak, Longest streak, Days completed, and Completion rate with its exact completed/eligible count.

Wide desktop panes display four columns aligned beside each routine’s date cells. Narrow panes and mobile use a compact section below the board, opened by activating a routine name. Stats stay independent of the visible date range and update when a check-in is corrected. There is no Rate period selector.

The completion rate excludes unscheduled and future days. Today is eligible when completed or after it ends. Frozen past days preserve the streak but add no completion credit. Routines with no eligible history show an em dash for the rate.

**Default change:** empty `habit-board` blocks now open Habit Board. Add `view: weekday-patterns` explicitly to retain the earlier empty-block heatmap. Explicit options for the other views are unchanged.

Today positioning, Jump to today, date/month headers, streak colors, and cell correction dialogs are preserved. The Today sidebar, routine editor, and analytics calculations remain unchanged. Phone-width testing uses desktop emulation; physical iPhone testing remains outstanding.
