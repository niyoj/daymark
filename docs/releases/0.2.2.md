# Daymark Habits 0.2.2

Fixes the API and CSS findings reported by the Community directory review.

- Use Obsidian's `createEl` helpers throughout the plugin views and routine editor.
- Keep the static weekday column count in CSS and apply dynamic styles with `setCssProps` and `setCssStyles`.
- Replace `!important` with scoped selectors for button typography and hidden editor panels.
- Keep completed tasks crossed out using basic `text-decoration`, without the flagged decoration color properties.
- Enforce `prefer-create-el` in the local lint configuration.

Validated with all 49 automated tests, the production build, release checks, and the published Obsidian CSS scanner rules with zero warnings for Electron 31 and newer (the target covering Obsidian 1.7.4). Real Obsidian checks covered the Today checklist, all four Markdown views, cell details, keyboard navigation, corrections, freezes, and editor panel visibility in light and dark themes. Narrow desktop viewports were used for mobile-width checks; no physical iPhone test was performed.

Existing records, schedules, streak calculations, and freeze rules are unchanged. Install in `.obsidian/plugins/niyoj-daymark/`.
